## 2. 画面遷移詳細

### 2.1 認証フロー

```
[未認証の状態でアクセス]
  │
  ├─ ACCESS_KEY が設定されている場合
  │   └─ アクセスゲート（403） ──?access_key=正解──→ 元のURL
  │
  └─ /login に遷移
      ├─ Legacy認証: メール/PW → 認証成功
      │   ├─ mustChangePassword=true → /change-password → 変更完了 → /
      │   └─ mustChangePassword=false → /
      │
      └─ Carrier認証: Googleボタン → Google OAuth → callback → /
```

### 2.2 一般ユーザーフロー

| 遷移元 | トリガー | 遷移先 |
|--------|---------|--------|
| 共通ヘッダー | 「ダッシュボード」リンク | `/` |
| 共通ヘッダー | 「セルフチェック」リンク | `/check` |
| 共通ヘッダー | 「360度評価」リンク | `/360` |

| 共通ヘッダー | 「ログアウト」ボタン | `/login` |
| `/` | テーブル行クリック | 同ページ内で詳細展開/閉じる |
| `/check` | 「AI採点を実行」ボタン | 同ページ内に結果表示 |
| `/360` | 「回答」ボタン | `/360/evaluate/[assignmentId]` |

## 3. ヘッダーナビゲーション構成

### 全ユーザー共通
| ラベル | パス | 説明 |
|--------|------|------|
| MDS AI判定 | `/` | ロゴ（ダッシュボードへ） |
| ダッシュボード | `/` | メインページ |
| セルフチェック | `/check` | AI採点 |
| 360度評価 | `/360` | 360度評価（従業員向け） |
| FAQ | 外部URL | `NEXT_PUBLIC_FAQ_URL` 設定時のみ表示 |

### admin のみ追加表示
| ラベル | パス | 説明 |
|--------|------|------|
| 社員管理 | `/admin/employees` | 社員マスタ |
| アカウント管理 | `/admin/accounts` | ユーザーアカウント |
| 360管理 | `/admin/360` | 360度評価サイクル管理 |

### ユーザー情報
- ユーザー名（または社員名）+ ロールバッジ
- ログアウトボタン

### レスポンシブ対応
- PC（lg以上）: 横並びナビゲーション
- モバイル: ハンバーガーメニュー → 縦並びドロワー

## 4. エラー画面・特殊状態

| 状態 | 表示 |
|------|------|
| 未認証でアクセス | `/login` にリダイレクト |
| admin以外が `/admin/*` にアクセス | `/` にリダイレクト |
| Google Sheets API 未設定 | ダッシュボードに青い案内バナー（「未設定です」） |
| Google Sheets API エラー | ダッシュボードに赤いエラーバナー |
| AI採点エラー | セルフチェックページに赤いエラーバナー |
| 提出済みの評価にアクセス | 「既に提出済みです」メッセージ + 戻るリンク |
| closedでないサイクルの評価にアクセス | 「回答を受け付けていません」メッセージ + 戻るリンク |
| 割当が見つからない | 「割当が見つかりません」メッセージ + 戻るリンク |
| データなし | 各テーブルに「データがありません」メッセージ |
| アクセスゲート（ACCESS_KEY設定時） | 「アクセスが制限されています」403ページ |
