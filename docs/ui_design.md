# MDS AI判定 画面設計書

最終更新: 2026-04-03

---

## 共通仕様

### デザインシステム
- **UIライブラリ**: shadcn/ui (Base UI) + Tailwind CSS v4
- **アイコン**: Lucide React
- **チャート**: Recharts（レーダーチャート）
- **フォント**: Geist / Geist Mono（Google Fonts）
- **カラー**: shadcn/ui のCSS変数ベーステーマ、背景 `bg-gray-50`

### レスポンシブ対応
- **ブレークポイント**: `sm`(640px), `lg`(1024px)
- **最大幅**: `max-w-6xl`（一覧画面）、`max-w-4xl`（詳細画面）、`max-w-3xl`（フォーム画面）、`max-w-2xl`（編集画面）、`max-w-sm`（ログイン画面）
- **モバイル**: テーブルは横スクロール (`overflow-x-auto`)、ハンバーガーメニュー

### 共通コンポーネント
- **Header**: 固定ヘッダー（`border-b bg-white h-14`）
- **Card**: 白背景のカードコンテナ
- **Table**: 行ホバーあり、レスポンシブ横スクロール
- **Badge**: ステータス表示（variant: default/secondary/outline/destructive）
- **Button**: プライマリ（default）、セカンダリ（outline）、ゴースト（ghost）
- **Skeleton**: ローディング中のプレースホルダー
